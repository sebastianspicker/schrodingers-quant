A breakout strategy, with the drawdown left in.

Schrödingers Quant is a Freqtrade spot bot for Kraken that ships in dry-run and starts stopped. Its strategy, H1, buys BTC/EUR when a 4h close breaks the 20-day high and sells when it breaks the 10-day low. This is the record of the backtests that decided whether it may move on to paper trading.

Verdict GO, marginal

H1 passed all four criteria written before the held-out run. The tightest, K2, it passed by 0.9 percentage points: its worst drawdown had to stay within 0.6 × buy-and-hold’s.

GO permits forward paper trading and a €10 execution test. It does not justify more capital.

Everything below is a historical simulation on Binance prices used as a proxy for Kraken. None of it is a live result or a forecast.

The rule, written before the test

H1 was predeclared with fixed rules, fixed periods and four criteria. All four must pass for GO. The held-out window was meant to be run once.

Why it is still weak evidence

  1. The held-out window was run twice. The first run compounded the stake, against the declared fixed stake, and failed K2 (+32.3 %, 35.1 % drawdown). The fixed-stake rerun is the one that counts. Both are published.
  2. Fourteen held-out trades, five winners. A few long trends carry the result.
  3. The family was chosen with hindsight. H1’s author, an AI model, knew how crypto prices moved up to mid-2026 when it picked a trend follower. Only the 20/10 channel lengths come from the literature.

So the next evidence has to come from data after 2026-09-24: forward paper trading on a VPS. Read the full experiment record.

How the bot is put together

Freqtrade is the only thing that places orders. Everything else checks, records or watches.

Ships inert

Project code never calls an order-creating method; a test fails if it does.
Exits never wait on a model
The optional Jev filter can only block new entries, and it fails closed.
Built for a small box
