# Fonts

Self-hosted so the demo makes no third-party requests. Text uses the system
sans-serif stack.

- `commit-mono-400.woff2`: Commit Mono 1.143 regular, SIL OFL 1.1
  (`CommitMono-OFL.txt`). Subset to Latin-1 plus the punctuation and symbols
  the page uses.

Built with fontTools (`pyftsubset`-equivalent API) from the upstream release
`eigilnikolajsen/commit-mono` v1.143.
