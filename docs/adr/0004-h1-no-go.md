# ADR-0004 — H1 is NO-GO; the held-out window is spent

**Date:** 2026-09-24. **Status:** superseded by [ADR-0005](0005-h1-go-after-sizing-correction.md) — the backtests behind this decision compounded the stake, contrary to H1.md.

## Context
H1 (20/10-day channel breakout, BTC/EUR 4h) was predeclared with decision rule
K1–K4 and evaluated once on the held-out period 2024-07-01 → 2026-09-20. See
[the experiment record](../../research/experiments/H1/record.md).

## Decision
NO-GO. Held-out net return was positive at base and stress costs (K1, K3) and
validation was positive (K4), but the marked-to-market drawdown of 35.1 %
exceeded the K2 limit of 0.6 × buy-and-hold (31.3 %). The Freqtrade
closed-trade drawdown (25.0 %) would have passed; it is not a like-for-like
comparison and is not used.

## Consequences
- `config/base.json` keeps the idle `BaselineStrategy`. `H1ChannelBreakout`
  stays in the repository as the evaluated reference strategy and as an
  optional order-flow exerciser for the dry-run soak (selected explicitly in a
  local overlay, never as the tracked default).
- Jev work stays gated: it needs a baseline that reached GO.
- Live-pilot tooling exists, but the €10 execution pilot waits for a GO
  strategy or an explicit decision to run it as an execution-only test.
- The 2024-07 → 2026-09 window has been seen. A successor hypothesis (H2) must
  be predeclared and judged on forward data collected after 2026-09-24 (forward
  paper trading), or on a pair/period not yet inspected. Sensitivity results
  (e.g. the 55/20 variant) are not a basis for selecting H2 on past data.
